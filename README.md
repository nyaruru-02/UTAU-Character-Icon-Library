# UTAU-Character-Icon-Library
UTAUアイコンの配布所


## ランダムガチャ共有とSNSサムネイル

`random.html?id=番号` で開くと、指定したIDのキャラクターを表示します。
X / Bluesky / Web Share API の共有URLもこの形式で生成されます。

SNSのリンクカード用サムネイルは `assets/ogp-random.png` です。
GitHub PagesのURLが `https://detective0615.github.io/UTAU-Character-Icon-Library/` ではない場合は、`random.html` 内の `og:image` / `twitter:image` / `og:url` を実際の公開URLに合わせて変更してください。

GitHubに反映後、XやBluesky側に古いサムネイルが残る場合があります。数分待つか、投稿URLを変えて再確認してください。
